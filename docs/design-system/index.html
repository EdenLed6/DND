01 · Direction

Light Fantasy Rulebook

Modern product usability wrapped in the visual language of an illustrated fantasy handbook.

Editorial, not SaaS

Use sections, dividers, tables and spreads before generic dashboard cards.

Dense but readable

D&D data stays visible. Hierarchy and rhythm create clarity without hiding rules.

Fantasy through craft

Parchment, ink, gold rules, watercolor and ornament—never neon gaming clichés.

Mobile at the table

Every core player action works with one hand on a 360–430px screen.
