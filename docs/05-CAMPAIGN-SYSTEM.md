# Campaign System / מערכת הקמפיין

ה-DM הוא בעל שליטה מוחלטת. השחקנים מנהלים רק את הדמות שלהם (אלא אם ה-DM דורס).

## A. Creating & Joining / יצירה והצטרפות

1. משתמש יוצר קמפיין → הופך ל-**DM** (owner). נוצר `inviteCode` ייחודי.
2. ה-DM משתף קוד/קישור הזמנה (`/join/{code}`).
3. שחקן נכנס עם הקוד → נוצר `CampaignMember(role=PLAYER)`.
4. השחקן יוצר דמות **בתוך הקמפיין** (או מצרף דמות קיימת) דרך אשף היצירה.
5. ה-DM רואה את כל הדמויות בלוח הקמפיין ברגע שנוצרות (live).

## B. DM Control Surface / משטח שליטת ה-DM

לוח הקמפיין של ה-DM כולל טאבים:

### 1. Party (הקבוצה)
טבלת כל הדמויות: שם, מקצוע+רמה, HP, AC, passive perception, XP, סטטוס.
לחיצה על דמות → **DM Edit Mode**: עריכת **כל שדה** בגיליון (override מלא) —
סטטים, HP, מיומנויות, קסמים, ציוד, מצבים, זהב. כל שינוי משודר לשחקן מיידית.

### 2. Progression (התקדמות)
- **מצב XP:** הזנת XP (ליחיד/לכל הקבוצה). כשדמות חוצה סף → תג "Level Up זמין".
  ה-DM יכול לאשר/לכפות עליית רמה (נפתח level-up flow לשחקן או נעשה ע"י DM).
- **מצב Milestone:** ה-DM מעלה רמה ידנית ללא XP.
- **Award XP מהקרב:** אחרי encounter, כפתור "Award" מחשב XP (brain §8) ומחלק.

### 3. Loot & Gold (שלל וזהב)
- **Party Loot:** רשימת פריטים שנמצאו (`LootItem`). ה-DM יכול "Assign" פריט
  לשחקן → עובר ל-inventory שלו (live).
- **Party Gold:** קופה קבוצתית (`Campaign.partyGold`). ה-DM מוסיף/מוריד ומעביר
  בין הקופה לדמויות. גם שליטה בזהב הפרטי של כל שחקן.
- הוספת פריטים מהקומפנדיום (SRD equipment/magic items) ישירות לשלל או לדמות.

### 4. Rest & Resources (מנוחה)
כפתורים: **Short Rest** / **Long Rest** — ליחיד או "Whole Party". מפעיל
`applyRest` (brain §13): מרפא HP, מחזיר hit dice, spell slots, resources,
מוריד exhaustion. שליטה ידנית בחידוש קסמים/משאבים ספציפיים.

### 5. Encounters & Maps
פתיחה/ניהול קרבות ומפות — ראה `06-COMBAT-AND-MAPS.md`.

### 6. Notes & Journal
הערות DM (dmOnly) והערות משותפות; יומן קמפיין; NPCs.

## C. Player View / תצוגת שחקן
- רואה את הדמות שלו (עריכה מלאה בכפוף למה שה-DM נעל).
- רואה את הקבוצה (סיכום בלבד, לא עריכה).
- רואה שלל/זהב קבוצתי (קריאה).
- מצטרף לקרב פעיל דרך התראה חיה.

## D. Live Behaviors / התנהגויות חיות (הדרישה המרכזית)
כל אלה משודרים לכל המחוברים לקמפיין בזמן אמת:
- DM עורך דמות → השחקן רואה מיד.
- DM מעניק XP → progress bar מתעדכן; תג level-up מופיע.
- DM מקצה שלל/זהב → מופיע ב-inventory של השחקן.
- DM מפעיל rest → HP/slots מתאפסים אצל כולם.
- שחקן מסמן spell slot/מצב → ה-DM והקבוצה רואים.
- כניסה/יציאה מקרב → כל הקבוצה עוברת למסך הקרב.

מנגנון: כל mutation → `emitToCampaign(campaignId, event, payload)` (ראה
`07-REALTIME-SYNC.md`).
