# SPEC v3 — בנייה מחדש דף-דף (2026-07-14)

מסמך עבודה: לכל דף — הצורך, מה קיים, מה חסר, ומי בונה. גל 1 רץ ב-6 סוכנים
מקביליים עם בעלות קבצים בלעדית; אינטגרציה, QA ואבטחה בגלים 2–4.

## עקרונות רוחב
- **קוביות**: בכל גלגול — רנדומליות קריפטוגרפית (`cryptoRandomInt`, בוצע).
  צורות אמיתיות לכל קובייה (d4 פירמידה, d6 קובייה, d20 איקוסהדר) — קיים
  ב-Dice Builder התלת-ממדי (dice3d). כפתורי גלגול ליד כל פעולה + מגירת
  קוביות צפה (FAB) — אין דף ייעודי (הסרת /dice מהניווט: אינטגרציה).
- **לוג גלגולים**: מודל RollLog חדש; פאנל בדף הדמות + הזנה מה-feed (אינטגרציה).
- **סנכרון מלא**: פעולה בקרב = אותו API כמו בדף הדמות (חוזה `op:"cast"`).

## חוזים בין סוכנים
- `POST /api/characters/[id]/spells` `{op:"cast", level}` → מוריד slot, מחזיר נותרים (A מממש, F צורך).
- `GET /api/campaigns/[id]/world-pages` מחזיר לשחקן רק public (D).
- homebrew: קריאה ישירה מ-prisma במסלולים של A/B; CRUD ב-E.
